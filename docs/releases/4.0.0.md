# Gecko in.touch 3 4.0.0

Breaking change: the integration now uses `gecko_intouch3`, allowing it to coexist with gazoodle’s local in.touch 2 integration. Existing cloud-account users must follow the README migration steps and take a Home Assistant backup first. The explicit importer transfers entity/device registrations using HA APIs, preserving entity IDs and rewriting entry-ID-based unique IDs. It does not import local in.touch 2 entries.

Thank you to @frenck for identifying the domain collision during HACS review, and to @gazoodle for maintaining the local in.touch 2 integration. HACS search is now the primary installation path, with custom-repository instructions retained while the catalog submission is pending.
